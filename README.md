# My personal website!
Source code for maxcyou.ru. Built with HTML, CSS and JavaScript.

## Run locally
Easily runs with python.
```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

## Files
- `index.html` — page structure
- `style.css` — styles and animations
- `script.js` — clock, navigation and project selection
- `assets/` — images and icons
